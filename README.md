# 🏎️ Toronto Supercar Expo 2026

A modern, interactive event website designed for the **Toronto Supercar Expo 2026** — a premium automotive experience showcasing high-performance vehicles, industry leaders, innovation, and automotive culture.

The project focuses on creating a professional event landing page with responsive design, interactive components, speaker showcases, event schedules, galleries, and an online registration experience.

# 🎯 Project Purpose

The goal of this project is to design and develop a professional event website that provides visitors with:

1. Information about the event
2. Event date and location
3. Featured speakers
4. Event schedule
5. Automotive gallery
6. Registration functionality
7. A modern and responsive user experience

The project demonstrates front-end development skills including **HTML, CSS, and JavaScript**.

- Navigation
- Hero section
- Event information
- Speaker cards
- Gallery
- Schedule
- Testimonials
- Location
- Registration modal
- Footer



### CSS3

CSS is used to create the visual design and responsive layout.

Main techniques include:

- CSS Grid
- Flexbox
- Responsive design
- CSS transitions
- Hover effects

- Typography
